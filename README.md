# core-pe-loader

core-pe-loader is a C project.

## Requirements

A C/C++ toolchain (GCC, Clang or MSVC), CMake 3.16 or newer or GNU Make.

## Build

```bash
make
```

## Run

```bash
./core-pe-loader
```

## Project structure

- `src/`
- `tools/`
- `Makefile`
